# hatfield-360

Work in progress.

## Development workflow

- Tasks are GitHub issues tracked through the **Hatfield Status** issue field (task-workflow plugin / Hatfield extension). Config: `.hatfield/settings.yaml`; hooks: `.hatfield/task-hooks/`.
- Observational memory is served by the local Librarian (`http://127.0.0.1:8093/_mcp`), configured in `~/.hatfield/settings.yaml`.
